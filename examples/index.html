maplibre-gl-lanes examples

Run corepack pnpm build first: these pages load the built bundle from /dist.

  • Classic script: no bundler, the global maplibreLanes.
  • Labels and chevrons: symbol layers along the lanes.
  • Highlight and popup: click a lane to lift its route.
  • Path colors: color by a property of the path, not the route.
  • Snapshot cache: store the lane order and reuse it.

The minimal bundler app is examples/bundler/, which has its own install; see the examples README.
